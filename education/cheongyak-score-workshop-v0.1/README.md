## 실습
exercise_cases.csv를 열고 예상 합계를 직접 구한 뒤 answer_key.csv로 검산합니다.

총점 = 무주택 점수 + 부양가족 점수 + min(17, 본인 통장 점수 + 배우자 인정점수)

A: 0+5+1 = 6점
B: 8+15+6 = 29점
C: 32+35+min(17,17+3) = 84점

C 사례에서 통장 인정점수 합계 20점이 아니라 항목 최대 17점을 적용합니다. 실제 무주택기간·부양가족·가입기간 인정 여부는 최신 입주자모집공고와 현행 제도에서 별도 확인해야 합니다.
