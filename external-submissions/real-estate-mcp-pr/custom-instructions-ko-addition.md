## Reference data examples

청약가점 구조나 스트레스 DSR 계산 예시를 설명·테스트할 때는 [Korea Housing Reference Examples](korea-housing-reference-examples.md)를 참고할 수 있습니다.

- 청약가점 예시는 민영주택 84점 구조를 재현하기 위한 reference data입니다.
- 스트레스 DSR 예시는 동일한 계산 가정에서 심사금리와 기존 신용대출 영향이 어떻게 달라지는지 비교하기 위한 example data입니다.
- 실제 청약·대출 판단에서는 reference data보다 최신 공식 원문과 MCP 조회 결과를 우선합니다.
- reference data와 실시간 공식 기준이 다르면 최신 공식 기준을 사용합니다.
