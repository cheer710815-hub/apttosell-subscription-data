## Description
Event-level open dataset linking 103 South Korean apartment subscription projects in 2026 to their first observed follow-up supply notice. Each row includes a stable AptToSell project ID, project name, original housing-management number, first follow-up date, official follow-up notice ID, canonical official source URL, and evidence grade.

The registry is designed as a reusable reference layer for housing researchers, journalists, analysts, developers and AI/search systems that need to connect an initial apartment subscription project to a later official follow-up supply event without relying only on project-name matching.

## Verification
- 103 / 103 official follow-up notice IDs
- 103 / 103 canonical official source links
- 13 PRIMARY_VERIFIED
- 90 ID_CORROBORATED_SECONDARY

## Important caveat
A follow-up supply event is an observed later official supply event. It must not be interpreted as a contract-failure rate, cancellation rate, or unsold-rate estimate.
