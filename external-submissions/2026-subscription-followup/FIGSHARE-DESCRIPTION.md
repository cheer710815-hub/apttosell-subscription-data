# Korea Apartment Subscription Competition and Follow-up Supply Analysis, 2026 Jan–Sep

## Description

This dataset provides derived summary statistics linking South Korean apartment presale announcements, first-priority subscription competition rates, presale-price bands, and later residual/unsold or optional-supply announcements.

The analysis uses initial recruitment announcements from 2026-01-01 through 2026-09-30 and an observation cutoff of 2026-10-04.

## Key statistics

- Final cohort: 196 projects
- Competition-rate coverage: 193 projects
- Projects with first-priority competition >=10:1: 44
- Projects with later follow-up supply among that group: 19
- Simple observed follow-up rate: 43.2%
- 60-day eligible projects: 36
- Follow-up supply within 60 days: 13
- 60-day follow-up rate: 36.1%

## Methodology note

Follow-up supply is not equivalent to a contract failure or non-contract rate. It only indicates that a later official residual/unsold or optional-supply announcement was matched to the initial project.

## Source

Korea Real Estate Board ApplyHome public API data.
