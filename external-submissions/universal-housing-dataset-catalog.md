## Dataset title
Korea Housing Subscription Score and Deposit Data 2026

## Dataset URL
https://github.com/cheer710815-hub/apttosell-subscription-data

## Publisher
AptToSell

## Geography
South Korea

## Topic
Housing subscription, apartment presale, eligibility reference data

## Description
Open reference data for South Korea's private-housing subscription system. The dataset includes the 84-point subscription score table, regional and housing-size subscription deposit requirements, CSV and JSON files, methodology, citation guidance, monthly snapshots, and canonical source pages.
