# Korea Apartment Initial Contract Cash Dataset 2026

AptToSell이 2026년 1~9월 아파트 최초 모집공고를 기준으로 계약금, 중도금, 잔금, 금융지원 방식과 입주 전 직접자금을 구조화한 데이터 프로젝트입니다.

## Current release
- Full validation registry: 196 projects
- Direct-cash calculable: 81 projects
- Conservative publication-ready subset: 41 projects
- Verification date: 2026-10-05

## Method
The project separates initial recruitment conditions from later residual/first-come sales promotions. Pre-move-in direct cash is calculated only where both the payment schedule and financing treatment are sufficiently verified.

## Important limitation
The current registry is project-level. A future institution-ready edition should expand to housing-type-level rows because payment schedules can differ by housing type within the same project.
