# Quality Checks — AptToSell Verified Project Registry 2026

A Version 1.0 public row should have:

- stable AptToSell project ID
- official or primary-source housing-management number
- official project name
- region and supply address
- first announcement date
- source traceability
- duplicate review completed
- verification date
- publication-ready flag

## Pilot warning

The current two-row pilot is structurally useful but not yet publication-ready because its source fields are not uniformly official.

Do not mint a DOI from this pilot.
