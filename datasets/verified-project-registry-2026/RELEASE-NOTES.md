# Release Notes — 0.4-pilot

Release date: **2026-10-05**

## Included

- Stable AptToSell project IDs assigned to **196 projects**
- Existing two pilot IDs preserved
- Housing-management numbers retained as external join anchors
- Crosswalk created for the **41-project pre-move-in funding public subset**
- Project-identity and competition-result verification kept separate

## Pilot status

This is a working identity layer, not a final authoritative registry.

`REGISTRY_SEEDED` means an AptToSell project ID has been assigned from the existing 196-project validation registry. It does not mean every row has independently passed the final primary-source identity gate.

## DOI decision

No DOI is assigned to version 0.4-pilot.

Version 1.0 should wait until:

- all publication-ready rows have primary-source identity verification
- duplicate/rename rules are frozen
- coverage scope is explicit
- regional code rules are finalized
- field-level verification flags are complete
