# Data Dictionary — Follow-Up Supply Linkage 2026

This linked file contains all original fields from the existing project-level competition/follow-up CSV plus:

| Field | Meaning |
|---|---|
| apttosell_project_id | Stable AptToSell internal project identifier |

Key inherited fields include:

| Field | Meaning |
|---|---|
| house_manage_no | Official housing-management number |
| project_name | Project name |
| initial_announcement_date | Initial recruitment announcement date |
| first_priority_competition_rate | Project-level first-priority competition rate |
| followup_supply_observed | Whether a follow-up supply event was observed |
| followup_event_count | Number of linked follow-up events in the analysis |
| days_to_first_followup | Days from initial announcement to first linked follow-up |
| eligible_60d_observation | Whether the project had at least 60 days of observation |
| followup_within_60d | Whether follow-up was observed within 60 days |
