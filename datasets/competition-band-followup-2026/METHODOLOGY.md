# Methodology

## 1. 분석 대상
최초 모집공고일이 2026-01-01부터 2026-09-30 사이인 APT 공고를 대상으로 했습니다. 조합원취소분, 공가세대, 추가입주자모집, 임차인모집 등 최초 일반분양 모집단과 성격이 다른 특수 공고는 제외했습니다. 최종 분석 모집단은 196개 프로젝트입니다.

## 2. 경쟁률 계산
평균 1순위 경쟁률은 `1순위 접수건수 합계 ÷ 일반공급 공급세대수 합계`로 계산했습니다. 주택형별 공급세대수는 MODEL_NO별 한 번만 합산하고, 1순위 접수건수는 해당지역과 기타지역을 모두 합산했습니다. 경쟁률이 확인되지 않은 3개 프로젝트는 별도로 분리했습니다.

## 3. 경쟁률 구간
- 1:1 미만: `rate < 1`
- 1~5:1: `1 <= rate < 5`
- 5~10:1: `5 <= rate < 10`
- 10~30:1: `10 <= rate < 30`
- 30:1 이상: `rate >= 30`

## 4. 후속공급 정의
최초 모집공고 이후 관측 기준일 2026-10-04까지 공식 데이터에서 APT 무순위·잔여세대 또는 임의공급 공고가 확인되면 `has_followup=1`로 분류했습니다.

## 5. 매칭 기준
1. 정규화 단지명 일치
2. 공급주소 완전 일치
3. 후속공고일이 최초 모집공고일 이후

## 6. 관측기간 보정
최근 공고는 후속공급을 관측할 시간이 짧으므로 전체 단순 발생률 외에 60일 및 90일 이상 관측 가능한 프로젝트만 분모에 넣은 표준화 지표를 별도로 계산했습니다.

## 7. 품질 검증
- 프로젝트 수: 196
- 주택관리번호 중복: 0
- 내부 project_id 중복: 0
- 단지명 누락: 0
- 최초공고일 누락: 0
- 경쟁률 확인: 193
- 경쟁률 미확인: 3
- 경쟁률 구간 배정 오류: 0

## 8. 해석 제한
`후속공급 발생률`은 계약률, 초기계약률, 미계약률 또는 청약 당첨자의 계약포기율을 의미하지 않습니다. 공식 후속공급 공고가 확인됐는지만 측정한 관측 지표입니다.
