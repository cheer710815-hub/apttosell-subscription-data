# 공공데이터포털 활용사례 등록 검토안 — N09

**상태: 등록안 준비 / 제출하지 않음 / 심사·게재 미확인**
**기존 중앙 작업대장 확인 후 별도 연구사례로 분류. 공식 등록처가 해당 형태의 연구를 수용하는지는 미확인.**

## 활용사례명
청약 경쟁률 10대 1 이상 주택형의 1차 무순위 공급 관측 데이터 — 25개 주택형·366세대

## 개발 유형
웹사이트 기반 데이터 분석·연구자료 공개 (등록 양식의 실제 항목 중 가장 정확한 유형을 선택)

## 서비스명
AptToSell

## 서비스 설명
AptToSell은 한국부동산원 청약홈 공식 공공데이터를 활용해 최초 해당지역 1순위 청약 경쟁률이 10대 1 이상이었던 주택형 가운데 이후 1차 무순위 공급공고가 확인된 사례를 분석했습니다. 최초 모집공고번호, 주택형 코드, 경쟁률과 1차 무순위 공고별 공급량을 연결했습니다. 총 28개 후보 주택형을 검토해 3개를 제외하고, 14개 사업의 25개 주택형에서 1차 무순위 공급 366세대를 관측했습니다.

검증 과정에서는 146세대에 대해 첫 무순위 모집공고 PDF 공급표를 대조했고, 220세대는 공식 API 응답 JSON 18개와 SHA-256, 주택형별 공급 수량을 재검증했습니다. 공개 데이터셋과 방법론, 검증 한계를 제공해 연구 결과를 재현·검토할 수 있도록 했습니다.

**해석 범위:** 관측된 366세대는 1차 무순위 공고의 공급 물량이며 미계약률·계약취소율이나 전국 무순위 발생 확률을 의미하지 않습니다. 220세대에 해당하는 9개 사업의 원공고 PDF 직접 대조는 DOI v1.0 발행 당시 완료되지 않았습니다.
