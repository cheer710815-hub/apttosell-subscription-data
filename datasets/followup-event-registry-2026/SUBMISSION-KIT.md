# Submission Kit — Follow-Up Event Registry 2026

## Short description

Event-level reference dataset linking 103 South Korean apartment projects in 2026 to their first observed follow-up supply notice. Each row includes a stable AptToSell project ID, official follow-up notice ID, first follow-up date, canonical official source link and evidence grade.

## Key figures

- 103 first follow-up events
- 103 / 103 notice IDs recovered
- 103 / 103 official source links
- 13 directly primary-verified rows
- 90 corroborated rows with ApplyHome official links
- CC BY 4.0
- No DOI assigned to this pilot
